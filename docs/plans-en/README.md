# Seedance 2.5 Ad Demo · Plan Index (organized by creative ad format)

> Organized into 9 categories by **the ad creative itself** (format type), removing the duplication that came from slicing by platform.
> One standalone doc per format type, each containing Branding ×3 + Performing ×3 (54 concise concept-level plans in total).
> The "platform rollout notes" inside each doc explain the exact specs and safe zones for that format on Meta / TikTok / Google / YouTube.
> How to sign off: open the relevant doc and change `- [ ]` to `- [x]` in front of the 1 Branding + 1 Performing you selected.

## Seedance 2.5 capability cheat sheet (short names referenced in every doc)

- **30s single-shot**: 30-second high-fidelity temporal extension in a single generation
- **50 reference assets**: up to 50 fully multimodal references (image / video / audio)
- **Local editing**: keep composition and camera work unchanged, swap the background / product / person to create variants
- **Multilingual**: native voiceover and instructions in 10+ languages
- **5 quality pillars**: lighting quality · motion rhythm · human performance · photorealistic camera work · small-object physical interaction
