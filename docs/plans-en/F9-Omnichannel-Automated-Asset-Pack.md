# F9 · Omnichannel Automated Asset Pack

- **Creative essence**: one set of multi-ratio, multi-variant assets fed to AI automation campaigns so the algorithm tests combinations itself, covering every channel
- **P/B positioning**: strongly P (AI auto-optimized conversion)
- **Category direction**: omnichannel e-commerce / DTC
- **Brand references**: Gymshark, Cider, automotive / retail / travel brands

## Core scenario

**Channel family: mixed (across Social / Video / Display / Search).**
This is not a fixed placement but **handing a diverse asset set to a platform's AI automation campaign** (Meta Advantage+ / Google Demand Gen / Performance Max), letting the algorithm allocate budget, combine assets and optimize conversion across every channel and placement automatically. The point is not to make "one perfect film" but to **supply variants in bulk across ratios, hooks and languages** so the algorithm has something to test — exactly where Seedance 2.5's shift "from generating one video → producing a set of deliverable ad assets" pays off.

## Ad types across platforms

| Platform | Ad type (placement name) | Asset requirements | Platform-specific notes |
|---|---|---|---|
| Meta | **Advantage+ Shopping** | Multiple diverse 9:16 assets | Feed it 3–5 hooks × 2–3 CTAs and let the AI test; requires a catalog + Pixel/CAPI |
| Google | **Demand Gen campaigns** | All three ratios (1:1 / 4:5 / 9:16) | Ad Strength needs ≥3 images per ratio to push toward Excellent; lifestyle beats white-background |
| Google | **Performance Max** | Images/videos in all three ratios | Always supply your own video (without it, the system stitches together a poor one from images); missing ratios cost you placements |

> General: the core capabilities are "50 reference assets" for consistency + "local editing" for batch variant derivation + "multilingual" for localization + "30s single-shot" to reduce stitching.
